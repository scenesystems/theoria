# Reporting security issues

Report vulnerabilities privately to [security@scenesystems.io](mailto:security@scenesystems.io)
or through [GitHub Security Advisories](https://github.com/scenesystems/theoria/security/advisories/new).
Keep details out of public issues, pull requests, and social media until disclosure is complete.

Include a description of the vulnerability and its likely impact, with steps to
reproduce it. Attach proof-of-concept code if available.

Maintainers will acknowledge the report within 48 hours and provide an initial
assessment within 7 days. Resolution depends on severity; maintainers will keep
you informed as they work on a fix.

Report security bugs in third-party modules to the person or team maintaining the module. You can also report a vulnerability through the [npm contact form](https://www.npmjs.com/support) by selecting "I'm reporting a security issue".
